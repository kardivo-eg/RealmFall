How to join
  1. Install the Modrinth AppFree launcher from modrinth.com/app.
  2. Find MedieCraft - LiteUse the button below to open the modpack page.
  3. Install the modpack and launch itPress Install, then Play.
  4. Add the serverGo to Multiplayer → Add Server and enter the address below.
  5. Click Done, select RealmFall, and join!If it says offline, press Start server above and wait a minute.
